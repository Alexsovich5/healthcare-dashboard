## Project Overview

Real-time healthcare operations dashboard using React 18 frontend, Node.js/GraphQL backend, and InfluxDB for time-series metrics including system uptime, incident tracking, and infrastructure health.

**Role**: IT Operations Specialist
**Organization**: AEL Dubai
**Duration**: October 2024 - December 2024
**Project**: #30 of 30 in IT Career Portfolio

## Business Impact

- **Single Pane of Glass**: Unified view of all healthcare IT systems
- **Real-time Monitoring**: Sub-second metric updates via GraphQL subscriptions
- **Executive Reporting**: Automated SLA and KPI dashboards
- **Proactive Alerting**: Threshold-based notifications

## Technology Stack

- **React 18**: Frontend with TypeScript
- **Node.js 20**: Backend server
- **GraphQL (Apollo)**: API layer with subscriptions
- **InfluxDB 2.x**: Time-series database
- **Docker**: Containerized deployment
